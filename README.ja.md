## プロジェクト概要

Fluxfall は 3D 農業シムの技術検証用プロジェクトである. 焦点は以下にある. 

* **自律エージェント**. **ジョブボード＋予約ベース選択**で動作する. **ユーティリティスコアリングは計画中**（ONI/RimWorld 相当の行動選択を目標）. 
* **ケイパビリティベースのアイテム**. インベントリ, クラフティング, エディタ時データベースを備える. 
* **確率的成長の作物**. 給水（ハイドレーション）制御. 見た目の段階と計算段階を分離. 
* **三人称 ARPG カメラ**. 照準クエリとインタラクション制御. 
* **エディタ支援の充実**. 著者作業と検証の短縮. 

本プロジェクトは, **システム間の明確な結合面**と**データ駆動のオーサリング**を重視する. 

---

## アーキテクチャ概観

* **Resources as truth**. アイテム, レシピ, 作物, SFX, ジョブを `Resource` として定義し, 差分管理と再利用性を確保. 
* **Signals/Callables**. エミッタ, マネージャ, インタラクト可能オブジェクトを疎結合化. 
* **Managers**. インベントリ, ジョブボード, 時間, オーディオなどの横断関心を小さなシングルトンで担当. 
* **タスク選択**. **予約ベース**（優先度・距離・スキル適合による簡易フィルタ）. ユーティリティスコアリングはロードマップ項目. 
* **Editor-first**. `@tool` インスペクタ, ベイクボタン, 条件付きプロパティで反復を短縮.

## コアシステム

### エージェントシステム

エージェントはジョブボードからジョブを発見・予約・実行する. 現状の選択は予約ベース（優先度・距離・スキル）であり, フルのユーティリティスコアリング層は計画中である. 

**主要要素**

* **Agent**. `CharacterBody3D`. `NavigationAgent3D`, アニメーションStateMachine, スタック検出, 回転/速度制御を備える. 
* **JobData**. `priority`, `required_skills: Dictionary[StringName,int]`, `item_requirements`, 順序付き `task_list` を持つリソース. 
* **Job Instance & Board**. 実行時インスタンスを中央ボードにエンキュー. エージェントが予約し, 失敗時は解放. 
* **Emitters**. 親ノードのシグナルを監視し, 比較規則と任意のバリデータでジョブ機会を投稿. インタラクト可能オブジェクトをエージェント内部から独立させる. 
* **Skills**. エージェントの `Dictionary[StringName,int]` を適合度に使用. 
* **Inventory 統合**. `ItemRequirement`（特定 ID またはケイパビリティ提供アイテム）に従い取得/消費. 
* **Debug Taskboard**. 待機中/実行中ジョブ, エージェント一覧, 再キュー/キャンセル, カメラフォーカスを可視化. 

**提案ユーティリティ/コストモデル（WIP）**
次式を設計目標とする. 

```
utility(job, agent) = w_d * f_distance(agent, job)
                   + w_i * f_inventory(job.requirements, agent.inventory)
                   + w_s * f_skill(job.required_skills, agent.skills)
                   + w_p * f_priority(job.priority)
                   + w_c * f_context(job, agent)  # ドメイン依存補正
```

* コストとして扱う（低いほど良い）か, 正規化/反転して用いる. 
* 文脈項は給水の緊急度, 収穫劣化などを扱う. 

**ジョブライフサイクル**

1. エミッタ/マネージャが**機会投稿**. 
2. **探索**. ボード照会（必要なら空間セルでフィルタ）. 
3. **予約**. トークン＋TTL で競合とスラッシングを抑制. 
4. **実行**. 順序付きタスク. 失敗処理とリトライを含む. 
5. **完了**. インベントリ入出庫などの副作用とシグナル. 

**移動と堅牢性**

* ナビゲーションコールバックで速度を更新. `stuck_time` により経路再計算やフォールバック操舵を実施. 
* 障害物判定はカメラ/インタラクション系と整合. 

**性能フック（計画/一部実装）**

* **空間分割**. ジョブ/インタラクト対象をグリッドでバケツ分け. 近傍セルのみ照会. 
* **再評価カデンス**. 照会のスタッガリングと指数バックオフでボード負荷を平準化. 
* **キャッシュ**. エージェント局所 LRU, およびボード側のケイパビリティ/タグ索引. 

### アイテム・インベントリ・クラフティング

**ケイパビリティ基盤**で継承増殖を回避. 

* **ItemResource**. 挙動を与えるケイパビリティスクリプト（例: Seed, Tool）を任意付与. 
* **ItemRequirement**. 

  * `StringName` による**特定アイテム**, または
  * ケイパビリティ実装アイテムによる**種別要件**. 
* **InventoryComponent**. 各エンティティの保管. **InventoryManager** がグローバル登録. 
* **クラフティング**. `is_consumed` ルールを尊重して消費/生成. 作業台シーンが UI を提供. 
* **エディタ QOL**. インスペクタからインスタンス生成, ケイパビリティ整合性検証, フォルダ走査による自動 DB 生成. 

### 作物システム

確率的成長, 給水制御, エージェント連携. 

* **状態**. `empty → planted → growing → harvestable`. 各状態で明確なハンドラ. 
* **成長モデル**. 成長ティック確率 `p = (1/I) * P_tick * P_grow`. **見た目段階**と**計算段階**を分離し, 平均/分散を独立制御. 
* **給水**. `hydration_changed` シグナル. デバッグ用 `always_hydrated`. 
* **ビルボード植物**. `BillboardPlantResource` に各段階のテクスチャ, UV 矩形, スケール, 垂直オフセットを保持. エディタボタンで再計算. アルファしきい値を調整可能. 
* **エージェント連携**. 閾値到達で水やり/収穫ジョブをエミット. 

### プレイヤーとカメラ

三人称 ARPG カメラ. オフセット考慮のオービット, 照準クエリ, インタラクション統合. 

### 昼夜・時間管理

* 中央の時間シングルトンがゲーム内分と時間倍率を提供. 
* 作物/エージェントはティックを購読. 睡眠/停止は時間倍率で表現. 

### オーディオ

* `SFXResource` がストリーム, 線形音量, ピッチ, ループを抽象化. 
* 3D 一発再生ヘルパで `AudioStreamPlayer3D` を生成. 減衰方式を選択. 
* `default_bus_layout.tres` による基本ミキシング. 


### UI・デバッグ

* **Debug Taskboard**. ジョブキューとエージェントを可視化. フォーカス, 再キュー, キャンセル操作. 
* 最小限のプロンプト/HUD. 目的は開発用デバッグである.

## エディタツール

* `_get_property_list` による**条件付きインスペクタ**（例: 重み付きルート vs 確定ドロップ, 特定アイテム vs ケイパビリティ要件）. 
* **ベイクボタン**でビルボード植物の UV/スケール/オフセットを事前計算. 
* **自動 DB 生成**. フォルダ走査でアイテム/レシピを登録. 
* **ジョブエミッタ設定**. シグナル名, 引数インデックス, 比較方式, 任意のバリデータ呼び出しを指定.

## ビルドと実行

1. **Godot 4.5+** を導入する. 
2. アドオンのローカル編集を行う場合はサブモジュール込みでクローンする. 

   ```bash
   git clone --recurse-submodules https://github.com/August13742/Godot-3DFarmingGame-Fluxfall-WIP.git
   ```
3. Godot でフォルダを開く. デフォルトシーンから実行可能.
4. オーディオバスは `default_bus_layout.tres` を参照する. 

> 入力マップと操作は三人称の標準設定に準ずる. 必要に応じて Project Settings で調整すること.

## ロードマップ

**優先（Immediate）**

* **空間分割＋選択アルゴリズム**（エージェント探索最適化）

  * ジョブ/対象を一様グリッドにバケツ分け. エージェントは近傍 K セルのみを照会. 
  * 予約トークン＋TTL を用いるコスト意識の**最短適格**選択. 
  * 再評価のスタッガリングと LRU による直近成功キャッシュ. 
* **ストレージシステムとネットワーク**

  * 容量・フィルタ・アクセスコストを持つチェスト/倉庫. 
  * 供給元/需要先の**近傍探索**と搬送ジョブの自動合成. 
  * インベントリの入出庫タスクを既存パイプラインに統合. 

**短期（Short-term）**

* 回避挙動, リトライ/バックオフ, ボード側のケイパビリティ/タグ索引の強化. 
* 作業台をジョブサイト化し, エミッタ連携を追加. 

**拡張（Stretch）**

* 簡易戦闘ジョブとテスト用モブ. 
* タウン/ワールドシーンと, システムを繋ぐ薄いゲームループ.
